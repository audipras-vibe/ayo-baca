# Ayo Baca!

Game browser untuk membantu anak usia 4–10 tahun belajar membaca dalam bahasa Indonesia. Pendamping menilai bacaan secara manual melalui tombol **Benar** dan **Ulangi Lagi**.

## Mainkan

[Buka Ayo Baca!](https://ayo-baca-anak.audi-prasetyo.chatgpt.site)

## Fitur

- Empat level membaca dengan 100 latihan unik per level.
- Pemisahan suku kata berwarna dan tingkat kesulitan bertahap.
- Koin, gacha hadiah, dan koleksi yang tersimpan di perangkat.
- Tampilan responsif untuk ponsel, tablet, dan desktop.
- Ramah sentuhan, mouse, keyboard, dan pengaturan reduced motion.

## Menjalankan secara lokal

```bash
pnpm install
pnpm dev
```

## Pemeriksaan

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```
